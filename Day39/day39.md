# Day 39 – PDF Splitter & Merger

## Overview

PDF Splitter & Merger is a browser-based PDF utility that performs document splitting and merging entirely on the client side without uploading files to external servers.

---

# What is PDF Splitter & Merger?

PDF Splitter & Merger is a productivity application for securely splitting, extracting, previewing, reordering, and merging PDF documents using client-side JavaScript.

---

# Purpose of the Application

- Split PDF documents
- Merge multiple PDFs
- Preview document pages
- Reorder PDF files
- Process PDFs locally for privacy
- Download processed PDF files
