How This AI Assistant Was Built (System Architecture & Prompt Engineering)

1. System Prompt Architecture ("The Assistant's Brain")

The system prompt establishes the persona of an encouraging Senior Staff Engineer & Tech Hiring Manager. Key design elements include:

  • Strict JSON Schema Enforcement: Forces Claude to return machine-readable JSON containing readiness_score, skill_gaps, resume_tweaks, roadmap, and portfolio_projects.
  • Edge-Case & Injection Guards: Treats all user inputs strictly as plain text data, preventing prompt injection attempts ("ignore instructions...").
  • Constructive Realism: Prohibits empty flattery, requiring every score and critique to be grounded directly in the provided tech stack and resume text.

2. Light UI/UX Design Choices

  • Modern Light Aesthetic: Built using a crisp white (`#FFFFFF`) and slate (`#F8FAFC`) color palette with vibrant indigo gradients (`#4F46E5` → `#7C3AED`) and soft shadows for maximum readability.
  • Interactive Multi-View Landing Page: Seamless view routing between an engaging Hero Home Page and the functional Candidate Evaluation Workspace.

3. Extension Capabilities

  • PDF Resume Extractor: Add PDF.js integration to allow file uploads.
  • Session Progress Tracking: Save previous readiness scores to localStorage to compute growth deltas over time.
